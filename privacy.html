Website hosting

This static website is hosted through GitHub Pages. When you load a page, GitHub processes technical request data required to deliver and secure the site. GitHub states that visitors’ IP addresses are logged and stored for security purposes.

The legal basis is Article 6(1)(f) GDPR. Our legitimate interest is providing a secure, reliable professional portfolio. GitHub processes its own operational data under the GitHub Privacy Statement.

AskCV assistant

AskCV is optional. When you submit a question, the following data is processed:

  • Your current question and up to four earlier questions from the same open page.
  • The generated answer and the public CV context needed to produce it.
  • Your IP address at the network edge and a salted SHA-256 hash created from it for request limits.

Processing path

The browser sends the question to a Supabase Edge Function. The function sends the question, limited question history, fixed instructions and Marco’s public CV to the Google Gemini API. Gemini returns an answer; the function validates it before displaying it.

Purposes and legal basis

The data is used to answer professional questions, prevent automated abuse and excessive costs, check answer quality and improve reliability. The legal basis is Article 6(1)(f) GDPR. The legitimate interests are presenting professional experience interactively, protecting the public service and correcting unsupported answers.

Retention

Questions and answers
Deleted after no more than 90 days. They are stored without a visitor account or visitor identifier.
Application IP hash
Deleted after no more than 3 days. The application database does not store the raw IP address.
Gemini processing
Google’s current Gemini API documentation states that prompts, context and outputs may be retained for up to 55 days for abuse monitoring.

Do not include confidential, sensitive or third-party personal information in an AskCV question. You can browse the complete portfolio and download the CV without using AskCV.

No automated decisions

AskCV provides informational answers only. Its output is not used to make a legal or similarly significant decision about a visitor.

Email contact

If you contact Marco by email, the contact details and message content you provide are processed to answer your request. The legal basis is Article 6(1)(b) GDPR where the exchange concerns a possible contract or role, and Article 6(1)(f) GDPR for other professional enquiries.

Messages are deleted when the enquiry is complete unless contractual, commercial or statutory retention requirements apply. The Email Marco button opens Google’s Gmail composer in a new tab; Google’s own privacy information applies to that page.

Cookies and analytics

This portfolio does not set cookies, use advertising trackers or run website analytics. It does not use browser local storage. External services are opened only when you choose a corresponding link, except for GitHub Pages hosting and the AskCV processing described above.

Recipients and international transfers

  • GitHub — static website hosting and security.
  • Supabase Pte. Ltd. — AskCV Edge Function, database and retention jobs.
  • Google — Gemini API answer generation and Gmail only if you open the email composer.

These providers or their subprocessors may process data outside the European Economic Area. According to their published terms, transfers use applicable safeguards such as adequacy decisions, the EU–US Data Privacy Framework or EU Standard Contractual Clauses. See the Supabase DPA, Gemini API terms and Gemini abuse-monitoring information.

Your rights

Subject to the legal requirements, you may request access, correction, deletion, restriction, data portability or object to processing based on legitimate interests. Contact marco.rohns12@gmail.com. Because AskCV logs contain no visitor account or visitor identifier, identifying a particular entry may not be possible without information from you that reliably matches the stored text.

You may also lodge a complaint with a data protection authority. The authority responsible in Lower Saxony provides an online complaint form.

The provision of data is voluntary. No statutory or contractual requirement obliges you to use AskCV or contact Marco.

Changes

This privacy information will be updated when the portfolio’s services or data processing change. The current version is identified by the date at the top of this page.
